# `wx.getLocation` 审核申请材料

适用小程序：`旅行计划吧`
生成日期：`2026-04-29`

## 一、推荐填写的接口申请理由

建议直接填写下面这版：

> 小程序“旅行计划吧”中的“随机玩/附近推荐”功能，需要在用户主动点击“微信定位”后获取当前地理位置，用于识别用户当前出发城市，并基于当前位置为用户筛选附近可出发的旅行目的地，计算目的地距离、推荐出行方向和行程方案。  
>  
> 该定位能力仅在用户主动使用“随机玩”或“附近出发”功能时触发，不会在后台持续获取，也不会用于社交、营销、无关画像等场景。  
>  
> 用户也可手动选择城市；若用户拒绝定位，小程序仍可继续使用手动选址功能。  
>  
> 因此，`wx.getLocation` 是本小程序“基于当前出发地推荐旅行目的地与生成行程”的核心必要能力。

## 二、补充说明

可在补充说明中填写：

> 用户路径为：首页进入“随机玩”页面 -> 主动点击“微信定位” -> 获取当前位置 -> 识别当前出发城市 -> 推荐附近旅行目的地 -> 用户查看距离、预算和推荐结果 -> 生成行程。  
>  
> 该接口不是静默获取，必须由用户主动点击触发；若用户拒绝授权，也可通过“手动选择城市”继续完成流程。

## 三、审核员关注点

提交时请尽量强调下面几点：

1. 用户主动点击“微信定位”才会调用定位接口。
2. 用途是识别当前出发城市，不是泛化的内容推荐。
3. 定位结果直接影响“附近目的地推荐”和“行程生成”。
4. 不做后台持续定位。
5. 拒绝授权时，用户仍可手动选择城市继续使用。

## 五、录屏讲解词

> 用户进入首页后，点击“随机玩”。  
> 在随机玩页面中，用户可以主动点击“微信定位”，系统获取当前位置，仅用于识别当前出发城市，并据此推荐附近适合出发的旅行目的地。  
> 如果用户拒绝授权，也可以手动选择城市继续使用。  
> 完成定位后，系统会展示附近目的地推荐、距离和预算信息，用户可继续生成行程。
