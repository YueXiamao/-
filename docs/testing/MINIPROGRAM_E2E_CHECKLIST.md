## 1. 目标

本清单用于验证当前小程序两条核心业务链路是否达到“可稳定交付”的基本要求：

1. 首页 -> 行程规划 -> 生成行程 -> 保存 -> 我的 -> 再次打开
2. 首页 -> 随机玩 -> 目的地推荐 -> 生成行程

同时覆盖关键异常流：

- 无定位权限
- 后端未启动
- 请求超时
- 空推荐
- 保存失败
