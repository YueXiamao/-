# UI 设计规范

**版本：** v1.0
**日期：** 2026-04-21

---

## 一、设计原则

1. **清晰优先** — 信息层次分明，用户一眼能找到关键操作
2. **轻量视觉** — 不做过度装饰，让内容（行程）成为主角
3. **操作友好** — 单手可及，关键按钮在屏幕下半部分
4. **反馈及时** — 每个操作都有明确的状态反馈

## 四、组件设计

### 4.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | 绿色实心圆角，`--color-primary` | 核心操作「生成行程」 |
| 次按钮 | 绿色边框透明底 | 次要操作「取消」 |
| 文字按钮 | 无边框无底色 | 辅助操作如「删除」 |
| 危险按钮 | 红色实心 | 删除确认 |

**状态：** Default / Hover（暗5%） / Active（暗10%） / Disabled（透明度50%）

### 4.2 标签（Tag）

| 类型 | 样式 | 用途 |
|---|---|---|
| 已选标签 | `--color-primary` 背景，白字 | 已选目的地、已选游玩方式 |
| 未选标签 | 白色背景，`--color-border` 边框 | 未选项 |
| 目的地 Tag | 带 × 图标，可删除 | 已选目的地列表 |

### 4.3 输入框

- 边框 `--color-border`，聚焦时 `--color-primary` 边框
- label 在输入框上方
- 错误状态红色边框 + 错误提示文字在下方

### 4.4 骨架屏

加载时用灰色占位块模拟内容布局：
- 标题：灰色长条
- 卡片：圆角矩形
- 列表项：头像圆 + 文字短条

## 六、动画规范

| 场景 | 动画 |
|---|---|
| 页面切换 | 默认小程序 slide 动画 |
| 标签选中 | 150ms ease-out 背景色切换 |
| 按钮点击 | scale(0.97) + 150ms |
| 骨架屏 | shimmer 动画，1.5s 循环 |
| 行程项滑出删除 | swipe-left 滑出，300ms |
| 推荐卡片切换 | 横向 fade 切换，300ms |

> 不使用复杂交互动画，避免性能问题。

## 视觉资产与城市背景补充规范（2026-04-23）

本节补充既有 UI 规范，不替代原有「清晰优先、轻量视觉、操作友好」原则。

### 1. 总体风格

- 采用「清透城市明信片」方向：低饱和、浅色调、有旅行感，但不使用暗色全屏照片或强装饰背景。
- 背景图只用于建立目的地氛围，不能承载按钮、状态、输入提示等关键信息。
- 表单、列表、行程内容和底部按钮必须放在清晰的内容层上，优先使用 `--color-surface` 或半透明白底。
- 年轻化表达通过卡片层次、轻插画、柔和城市色调和按压反馈完成，不通过 emoji 或高饱和渐变完成。

### 2. 背景图分类

背景图作为本地静态资源放在 `frontend/assets/backgrounds/`：

| 类型 | 文件 | 适用目的地关键词 | 色调 |
|---|---|---|---|
| 山水古城 | `city-mountain.png` | 成都、都江堰、重庆、西安、桂林、张家界 | 青绿、米白、浅金 |
| 海岸周末 | `city-coast.png` | 厦门、三亚、青岛、舟山、海口、大连 | 海蓝、沙色、浅青 |
| 都市夜游 | `city-urban.png` | 上海、北京、深圳、广州、杭州、南京 | 蓝灰、暖橙、浅紫灰 |
| 雪山高原 | `city-snow.png` | 丽江、大理、拉萨、香格里拉、西宁 | 冷蓝、雪白、浅棕 |
| 江南水乡 | `city-water.png` | 苏州、无锡、嘉兴、湖州、绍兴、扬州 | 水绿、雾白、淡墨 |
| 通用城市 | `city-default.png` | 未命中关键词时 | 绿灰、米白、浅橙 |

### 3. 偏好方式图片

偏好方式图片作为本地静态资源放在 `frontend/assets/pref-icons/`，命名沿用当前常量引用。图片内容必须准确表达偏好含义：

- `vacation.png`：轻松度假，表现躺椅、太阳、慢节奏。
- `checkin.png`：网红打卡，表现取景框、地标、拍照构图。
- `food.png`：寻找美食，表现餐碗、蒸汽、餐桌。
- `family.png`：亲子友好，表现家庭出行和安全感。
- `culture.png`：文化探索，表现古建、展馆、书页或纹样。
- `hiking.png`：户外徒步，表现山路、路线、树线。
- `shopping.png`：购物休闲，表现购物袋、街区、橱窗。

图片尺寸建议为 240×240 PNG，背景透明或浅色块，避免复杂细节导致小尺寸下不可辨认。
