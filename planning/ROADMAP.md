## v2.0 — 增长阶段

### 目标

在 MVP 基础上增加个性化推荐能力，扩大城市覆盖，提升用户留存。

### 交付内容

#### 功能增强

| 功能 | 说明 | 优先级 |
|---|---|---|
| 用户行为埋点 | 记录用户浏览/点击/删除/收藏行为 | P0 |
| 标签冷启动推荐 | 根据用户历史选择匹配目的地标签 | P0 |
| 城市扩展 | 从 20 个热门城市扩展到 100 个 | P0 |
| 行程分享图片 | 生成分享海报图片（Canvas 绘制） | P1 |
| 行程收藏 | 收藏行程到「我的」页面 | P1 |
| 历史行程对比 | 两套行程并排对比 | P2 |

#### 数据增强

| 内容 | 说明 |
|---|---|
| 目的地标签完善 | 为 100 个目的地打标签（人工+AI 辅助） |
| POI 评分排序 | 根据用户实际访问数据计算 POI 真实评分 |
| 目的地摘要文案 | AI 生成 + 人工润色每个目的地的推荐理由 |

#### 性能优化

| 指标 | 目标 |
|---|---|
| AI 生成 p95 延迟 | < 8s（从 10s 优化） |
| 页面首次渲染时间 | < 1.5s |
| POI 缓存命中率 | > 80% |

## v3.0 — 智能化阶段

### 目标

引入协同过滤推荐算法，实现「越用越懂你」的效果。

### 交付内容

#### 智能推荐

| 功能 | 说明 |
|---|---|
| 用户相似度计算 | 基于目的地选择+偏好标签计算用户相似度（余弦相似度） |
| 协同过滤召回 | 相似用户喜欢的目的地优先推荐 |
| Embedding 语义检索 | 将目的地描述向量化，做语义匹配（突破关键词局限） |
| 行程内容排序优化 | 根据用户历史「删除/隐藏」行为调整 POI 排序权重 |

#### 用户激励

| 功能 | 说明 |
|---|---|
| 打卡成就系统 | 用户完成行程后可打卡，获得成就徽章 |
| 评价系统 | 用户对行程中的景点/餐厅可评分（1-5星） |
| 社区分享 | 用户可分享自己的行程到「发现」页（UGC） |

#### 数据分析平台

| 功能 | 说明 |
|---|---|
| 运营看板 | DAU/MAU、行程生成数、AI 成功率、Top 目的地 |
| 反馈分析 | 用户删除/隐藏行为的统计分析 |
| AI 质量监控 | Prompt 效果评估、模型切换效果对比 |

## 版本切换策略

```
v1.0 开发期间：
  - 所有人开发 feature 分支，合并到 develop
  - develop 不对外服务

v1.0 上线后：
  - v1.0 代码冻结为 main
  - develop 继续 v2.0 开发

v2.0 上线后：
  - v2.0 代码冻结为 main
  - develop 继续 v3.0 开发
```

每个正式版本打 Git Tag，格式：`v1.0.0`、`v2.0.0`。
